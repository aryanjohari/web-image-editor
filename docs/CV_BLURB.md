## Paragraph (~80 words)

Prism is a personal still-photo styling engine I built to explore parametric looks without generative pixels. Users upload a photo, apply one of eight named packs, tune semantic and regional sliders, and optionally describe intent via a Gemini-backed talk router that patches a closed recipe schema — the same document manual sliders edit. A WebGL2 compositor renders live preview and export; MediaPipe supplies a person mask for subject/background grade. The project shipped v1 through research-gated modules (field research, constitution, M00–M07) with full PNG, recipe JSON, and hero-lite export.
